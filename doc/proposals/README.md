# Proposals

Design proposals for changes that are not implemented yet.

A proposal is a working document: it records the problem, the decisions taken,
the rationale behind each one, and the questions still open. It is written
before the code, reviewed as a design, and deleted (or folded into
`doc/architecture/` and `doc/reference/`) once the change lands.

Nothing in this directory describes the shipped library. It is excluded from
the Sphinx build for that reason — see `exclude_patterns` in `doc/conf.py`.
